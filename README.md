# Calc-calculator-
Denna upgift som jag har genomför är en funktionerande kalkylator gjord inom html, CSS och Javascript. Poängen med denna upgift är att träna och förbättra mina kundskaper inom Javascript. 
Först vill jag diskutera min HTML fil. HTML filen är den minsta delen av detta arbete därför finns det inte särskilt mycket att anmärka men den följder det typiska formatet som en HTML fil borde ha, alltså en header som länkar till min CSS, Javascript och ett mattematik bilbliotek. 
Sedan finns en body där det finns en main som inehåller fyra divvar, två av dem gör upp i princip hela uppgiften. Den första är min "display" div som är området där alla tecken som trycks in i miniräknaren sparas och eventuellt räknas ut. Divven har ett simpelt id som heter "display" och börjar tom. Den andra och viktigaste divven i detta projekt är min "calc" div, denna div inehåller alla knappar med tecken på min kalkylator.
